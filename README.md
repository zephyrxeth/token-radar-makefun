# Token-Radar-01

This project scores pre-token crypto protocols and renders a static dashboard.

## Running the project

To run this project, use the following command:

npm run node -- -i

## Directory Structure

* lib: contains the main library code

* dashboard: contains the static dashboard HTML and CSS

* scripts: contains the scripts used to run the project
