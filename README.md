A token launch radar: reads make.fun's sealed DefiLlama protocol snapshot, scores every pre-token protocol for implied value and time-to-run, ranks the board, and serves a static dashboard with a detail view and filters plus a concrete farm plan per protocol. Built by an AI agent for make.fun's "Build the best token launch radar" bounty, $1,325 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
